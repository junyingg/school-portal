# Requirements

One row per requirement in the brief: how it is met, where, which tests prove it, and its status. Test titles are quoted exactly as they appear in the test files; Postman entries name the request in `postman/school-portal.postman_collection.json`. For the code walk-through see [ARCHITECTURE.md](ARCHITECTURE.md); for the reasons see [DECISIONS.md](DECISIONS.md).

Status: **done**, **partial** (with the reason), or **not done** (with the reason).
